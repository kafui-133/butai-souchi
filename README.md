# 舞台装置 — SF概念図鑑

SFに登場する概念・マクガフィンを、

1. **アニメーション**（パラメータを動かせるインタラクティブなシミュレーション）
2. **出典・元ネタ**（初出作品や科学論文の年表）
3. **物理と数式**（KaTeXで描画）
4. **現時点での実現可能性**（5段階評価＋主なマイルストーン）

の4つの視点から解説するWebアプリです。ビルド不要の静的サイトです。

## 宇宙世紀年表（`uc.html`）

『機動戦士ガンダム』シリーズの宇宙世紀の主な出来事を、地球・月・ラグランジュ点の地図上でアニメーション再生する別ページです。
宇宙での出来事はその場所（サイド、要塞、月面都市など）を表示し、地上の出来事では地球にクローズアップします。
コロニー落としは、宇宙から落下地点までを続けて描きます。年表データは `js/uc-data.js` にあります（非公式のファン向け解説）。

## 起動方法

```bash
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

`index.html` をブラウザで直接開いても動作します（Webフォントのみネット接続が必要。数式ライブラリ KaTeX は `vendor/` に同梱）。

## ファイル構成

```
index.html          画面の骨組み
css/style.css       スタイル
js/data.js          各概念の解説・出典・数式・実現可能性データ
js/animations.js    各概念のCanvasアニメーションと計算ロジック
js/app.js           ルーティング、UI生成、アニメーション制御
uc.html             宇宙世紀年表ページ
js/uc-data.js       宇宙世紀年表のデータ
js/uc.js            宇宙世紀年表の地図・地球の描画と再生制御
css/uc.css          宇宙世紀年表ページのスタイル
vendor/katex/       KaTeX 0.16.11（MITライセンス）
```

### 概念を追加するには

1. `js/data.js` の `CONCEPTS` 配列に、既存のエントリと同じ形式でオブジェクトを追加する。
2. `js/animations.js` に、同じ `id` で `ANIMS.<id> = { controls, create }` を追加する。
   - `controls`：`range`（`log: true` で対数スライダー）、`select`、`button` が使える
   - `create(ctx, view, P)` は `update(dt)`、`draw()`、`readouts()`、（任意で）`action(id)` を持つオブジェクトを返す

## 注意

物理量の数値は代表的な文献値や概算です。アニメーションの一部（温室効果の灰色大気モデルなど）は理解のための簡略化モデルです。
