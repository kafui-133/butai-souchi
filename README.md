# 舞台装置 — SF概念図鑑

SFに登場する概念・マクガフィンを、

1. **アニメーション**（パラメータを動かせるインタラクティブなシミュレーション）
2. **出典・元ネタ**（初出作品や科学論文の年表）
3. **物理と数式**（KaTeXで描画）
4. **現時点での実現可能性**（5段階評価＋主なマイルストーン）

の4つの視点から解説するWebアプリです。ビルド不要の静的サイトです。

## 作品年表（`uc.html`）

SF作品の歴史を、舞台となる宇宙の地図の上でアニメーション再生する別ページです。上部のタブで作品・暦を切り替えます。

- **ガンダムシリーズ**：宇宙世紀（外伝を含む約40件）、未来世紀、アフターコロニー、アフターウォー、正暦、コズミック・イラ、西暦（00）、A.G.、リギルド・センチュリー、P.D.、アド・ステラ
  - 地球・月・ラグランジュ点の地図で表示し、地上の出来事では地球にクローズアップします。コロニー落としは宇宙から落下地点までを続けて描きます。
- **マクロス**：地球圏の時代（1999〜2040年、マクロス ゼロ・超時空要塞マクロス・マクロスプラス）と銀河の移民船団（マクロス7・マクロスF・マクロスΔ）。歌の場面では音の輪と音符の演出が入ります。
- **エヴァンゲリオン**：TV版・旧劇場版（セカンドインパクトからサードインパクトまで19件）と新劇場版（序・破・Q・シンの15件）。地球・月の地図で表示し、地上の出来事は地球に寄って見せます。
- **スター・ウォーズ**：銀河共和国の成立から映画9部作、クローン・ウォーズ、反乱者たち、ローグ・ワン、マンダロリアンまで28件。コア・ワールド〜アウター・リムと主なハイパースペース航路の模式図で、惑星の破壊やライトセーバーの決闘も描きます。
- **銀河英雄伝説**：銀河帝国・自由惑星同盟・二つの回廊の模式図で表示し、会戦では星域に寄って艦隊戦を描きます。艦隊の進軍ルートも表示します。

年表データは `js/uc-data.js`（宇宙世紀）と `js/worlds.js`（各作品の世界）にあります。年表ページ右上の検索欄で、全作品の出来事を人物・場所・用語で検索できます。URLの末尾に `#logh` や `#ce` を付けると、その作品の年表を直接開けます（非公式のファン向け解説）。

## 公開（GitHub Pages）

`main` ブランチに push すると、`.github/workflows/pages.yml` が自動でサイトを GitHub Pages に公開します。
初回のみ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。
公開URL：https://kafui-133.github.io/butai-souchi/

## 起動方法

```bash
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

`index.html` をブラウザで直接開いても動作します（Webフォントのみネット接続が必要。数式ライブラリ KaTeX は `vendor/` に同梱）。

## ファイル構成

```
index.html          画面の骨組み
css/style.css       スタイル
js/data.js          各概念の解説・出典・数式・実現可能性データ
js/animations.js    各概念のCanvasアニメーションと計算ロジック
js/app.js           ルーティング、UI生成、アニメーション制御
uc.html             作品年表ページ
js/uc-data.js       宇宙世紀の年表データ
js/worlds.js        作品年表の世界（暦）の定義と各作品の年表データ
js/uc.js            作品年表の地図・地球・銀河の描画と再生制御
css/uc.css          作品年表ページのスタイル
vendor/katex/       KaTeX 0.16.11（MITライセンス）
```

### 概念を追加するには

1. `js/data.js` の `CONCEPTS` 配列に、既存のエントリと同じ形式でオブジェクトを追加する。
2. `js/animations.js` に、同じ `id` で `ANIMS.<id> = { controls, create }` を追加する。
   - `controls`：`range`（`log: true` で対数スライダー）、`select`、`button` が使える
   - `create(ctx, view, P)` は `update(dt)`、`draw()`、`readouts()`、（任意で）`action(id)` を持つオブジェクトを返す

## 注意

物理量の数値は代表的な文献値や概算です。アニメーションの一部（温室効果の灰色大気モデルなど）は理解のための簡略化モデルです。
